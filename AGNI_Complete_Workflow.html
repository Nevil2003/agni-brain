1. Executive Summary

AGNI is a wearable gut-acoustic monitoring patch. It listens to bowel sounds via a MEMS microphone, counts them per minute, tracks the interval between them (SSI), and delivers one daily trend over WhatsApp.

The core insight: The FDA-cleared AbStats system (K150782) proved that simply counting bowel sound events per minute provides clinically valuable gut-health tracking — 100% sensitivity, 97% specificity for gastrointestinal motility assessment. AGNI replicates this proven approach at consumer cost with Indian supply chain and WhatsApp delivery.

No ML required for MVP. No Ayurveda mapping needed. The strongest science is the simplest: count bowel sounds, measure time between them.

Physical Assembly

  1. Cut stethoscope tube ~3cm from the bell end
  2. Hot-glue INMP441 inside the bell opening, diaphragm-facing
  3. Surround mic with foam tape to isolate from case vibration
  4. Seal bell opening with Tegaderm (remove backing, place on skin)
  5. Apply ultrasound gel between diaphragm and skin
  6. Run wires to XIAO on breadboard (worn on waistband/belt or next to you)
  7. Lie supine. Attach to upper-right abdomen (right lower quadrant is standard clinical site)

5. Firmware — Arduino Code for XIAO

I2S Audio Capture @ 16 kHz

// ==========================================
// AGNI — I2S Bowel Sound Recorder
// XIAO nRF52840 Sense + INMP441
// Sampling: 16 kHz, 16-bit, mono
// ==========================================

#include <I2S.h>

const int sampleRate = 16000;
I2S i2s(INPUT);

void setup() {
  Serial.begin(115200);
  while (!Serial);
  
  if (!i2s.begin(I2S_PHILIPS_MODE, sampleRate, 16)) {
    Serial.println("I2S init failed!");
    while (1);
  }
  Serial.println("AGNI_RECORDING:16000Hz");
}

void loop() {
  int samples[512];
  int idx = 0;
  
  while (idx < 512) {
    int sample = i2s.read();
    if (sample != 0 && sample != -1) {
      samples[idx++] = sample;
    }
  }
  
  // Send 512 samples as binary (4 bytes each)
  Serial.write((uint8_t*)samples, 512 * sizeof(int));
}

Upload instructions: Install XIAO nRF52840 board package in Arduino IDE. Select "Seeed XIAO nRF52840 Sense" as board. Upload via USB.

6. Python DSP Pipeline

Run on laptop connected via USB. Takes raw 16 kHz audio → bandpass filter → event detection → rate + SSI.

# ==========================================
# AGNI — Real-Time DSP Pipeline
# Bandpass → ST Energy → Events → Rate + SSI
# ==========================================

import numpy as np
import scipy.signal as signal
import struct, serial, time

SAMPLE_RATE = 16000
PORT = 'COM3'  # Windows. Linux/Mac: '/dev/ttyACM0'

# Butterworth bandpass 80-1000 Hz, 4th order
b, a = signal.butter(4, 
    [80/(SAMPLE_RATE/2), 1000/(SAMPLE_RATE/2)], 
    btype='band')

# Adaptive threshold (running mean + 2*std)
WINDOW_SEC = 30       # recompute threshold every 30s
MIN_RATE = 1          # ignore rates below 1/min (noise floor)

ser = serial.Serial(PORT, 115200, timeout=1)
print("AGNI DSP — waiting for data...")

# Wait for start marker
while True:
    line = ser.readline().decode().strip()
    if "AGNI_RECORDING" in line:
        print("Connected. Listening...")
        break

buffer = []
recent_rates = []
data_log = []

while True:
    # Read 512 int samples
    raw = ser.read(512 * 4)
    if len(raw) < 512*4:
        continue
    samples = struct.unpack('<' + 'i' * 512, raw)
    buffer.extend(samples)
    
    # Process every 2048 samples (128ms)
    while len(buffer) >= 2048:
        chunk = np.array(buffer[:2048], dtype=np.float32)
        buffer = buffer[2048:]
        
        # Bandpass filter
        filtered = signal.filtfilt(b, a, chunk)
        
        # Short-time energy (32ms windows)
        energy = []
        for i in range(0, len(filtered)-512, 256):
            frame = filtered[i:i+512]
            energy.append(float(np.mean(frame**2)))
        energy = np.array(energy)
        
        # Adaptive threshold
        thresh = float(np.mean(energy) + 2 * np.std(energy))
        events = energy > thresh
        
        # Rate (events/min)
        n_events = int(np.sum(events))
        rate = n_events / (len(energy) * 0.016 / 60)
        
        # SSI — time between events (ms)
        if n_events > 1:
            idx = np.where(events)[0]
            intervals = np.diff(idx) * 16  # ms
            ssi = float(np.mean(intervals))
        else:
            ssi = 0.0
        
        recent_rates.append(rate)
        if len(recent_rates) > 100:
            recent_rates.pop(0)
        avg_rate = float(np.mean(recent_rates))
        
        # Log
        t = time.strftime("%H:%M:%S")
        print(f"[{t}] Rate: {rate:.1f}/min | Avg: {avg_rate:.1f} | "
              f"SSI: {ssi:.0f}ms | Events: {n_events}")
        
        data_log.append({
            'time': time.time(),
            'rate': rate,
            'ssi': ssi,
            'events': n_events
        })

7. Testing Protocol

Week 1: Signal Capture & Validation

1

Build & Verify Circuit

Wire INMP441 → XIAO per diagram. Flash I2S capture code. Open Serial Monitor — you should see "AGNI_RECORDING:16000Hz".

2

Record + Audacity Check

Run Python DSP. Record 10 minutes lying supine with patch on upper-right abdomen. Open the raw WAV in Audacity, apply 80-1000 Hz bandpass filter. You should see irregular bursts above the noise floor.

✅ PASS: Distinct bowel bursts visible after bandpass. SNR >2-3× above noise floor.

Week 2: Baseline Calibration (3 days)

3

30-min Fasting Recording

Morning before any food. Lie supine, patch on. Record 30 min. Save CSV log.

✅ EXPECTED: Rate 5-34/min (textbook normoactive). SSI ~1,700-2,000 ms (Craine 2002 healthy adult range).
4

90-min Post-Meal Recording

After standard breakfast (idli/dosa or your usual meal). Note what you ate. Record 90 min.

✅ EXPECTED: Rate peaks at ~90 min post-meal (Cohen 2021). SSI drops significantly (shorter intervals = active digestion).
5

Repeat × 3 Days

Same meal, same time, same position. Compare trend.

✅ PASS: Reproducible rate/SSI pattern across days. Post-meal rate increase is consistent.

Week 3: Meal Challenge

6

Small vs Large Meal Comparison

Day 1: Light snack (chai + biscuit). Day 2: Full meal (thali). Compare rate/SSI response curves.

✅ EXPECTED: Large meal produces higher rate peak, longer duration of elevated activity (Cohen 2021 — AbStats distinguished 360 kcal vs 1,110 kcal meals).

Week 4: Wear & Delivery

7

Standalone Recording + BLE

Program XIAO to compute rate/SSI on-device, send daily JSON over BLE to phone.

✅ PASS: No laptop needed. Device runs on battery for 3+ hours continuous.
8

WhatsApp Delivery

Daily trend: "Your gut today: Rate 18/min (normal range 5-34). SSI 1,200ms. Steady compared to your baseline."
